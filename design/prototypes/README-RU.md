# Smart Contractor — гибридный мобильный прототип

Рабочая предварительная версия, 13 октября 2026.

Визуальная основа: Glassy UI Dark Theme Real Estate (Daniel Boeppler, Dribbble shot 27442264). Поведение: AI Phone OS thinking mode (shot 27637405). Собственная реализация React/TypeScript: код авторов Dribbble не извлекался и не покупался. Вечерний дом создан специально для этого прототипа, дневные фотографии взяты из существующего проекта Alpha Lux и являются иллюстративными.

Работают: пять разделов, тёмная/светлая тема, два режима кабинета, создание проектов с валидацией и локальным сохранением, карточка проекта, пример этапов работ и одобрения, сохранение идей, локальный чат, резервирование демонстрационной заявки и отмена, раскрывающаяся панель помощника с анимированной последовательностью и переносом текста в заявку. Reset preview в кабинете возвращает образцы.

## Запуск

Node.js 22+, затем `npm ci` и `npm run dev`. Для сборки `npm run build`. Для проверки шаблона `npm run check:runtime`, для упаковки `npm run test:sites`.

Основной интерфейс: src/Prototype.tsx и src/prototype.css. Системная рамка, клавиатура, статусная строка и переключатель iPhone/Pixel сохранены из мобильного шаблона.

## Связь с существующим приложением

Прочитаны AGENTS.md, ARCHITECTURE.md и smart-contractor-app.html репозитория Melxisedek75/gcsc-smart-contractor. Перенесены продуктовые сценарии проектов, кабинета подрядчика, этапов и защиты платежей. Репозиторий и приложение на телефоне не изменены. Доступа к телефону нет.

Этот пакет — отдельный frontend-прототип. Текущий backend Express/PostgreSQL/JWT, Stripe, escrow и XPR не подключены. Перед интеграцией нужно сверить реальные endpoints v3/server.js, определить адаптер проектов/заявок/сообщений, использовать текущую авторизацию и серверную проверку ролей. Не заменять финансовые операции локальными состояниями. Не изменять on-chain слой или treasury ради оформления.

## Границы демонстрации

Данные проектов, идей и сообщений хранятся в localStorage текущего браузера. Чат ничего не отправляет подрядчикам. Резерв $25 и одобрение этапа ничего не списывают. AI-план фиксированный, анимация не означает запрос к модели. Учетная запись Alexander — образец. Авторизация, загрузка файлов, push-уведомления, доступность реальных подрядчиков и APK/iOS-сборка пока отсутствуют.

## Проверка

Production build и 4 теста упаковки прошли. 28 файлов мобильного runtime не изменены. Через браузер проверены создание и сохранение проекта, перенос из помощника, чат, избранное, роли, резерв заявки, смена темы. Ошибок приложения в console по terminal.local не выявлено; браузерная extension выдаёт собственные сообщения.

Визуальная проверка полного масштаба 1:1 остаётся открытой: доступный браузер уменьшает телефон до 0.917 масштаба. См. design-qa.md. Это предварительный прототип для выбора направления, а не финальная производственная версия.
