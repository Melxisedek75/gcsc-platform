### Непрерывность работы

`CHECKLIST.md` задаёт порядок задач, `WORK-LANES.md` - владельца изменений,
`ACTIVE-TASK.json` - точку продолжения. Запуск следующего цикла обеспечивает
расписание Codex, а не текст этих файлов. После безопасного шага сразу брать
следующий готовый пункт. На следующем запуске сверить актуальный checkpoint,
рабочие деревья и активных исполнителей; не повторять неизменные проверки ради
активности. Блокер одной lane не останавливает остальные. Отсутствие ответа
владельца не разрешает live-действия. Пауза всей автоматизации допустима только
по прямой просьбе владельца, при исчерпании лимита, после 31 октября либо после
проверки всех разрешённых lane, когда ни одной безопасной задачи действительно
нет; тогда сохранить точный блокер и уведомить владельца один раз.

«Входит в мировой топ-3» не является проверяемым техническим статусом и не может
быть гарантировано или заявлено без внешнего признания. Рабочая цель: оригинальный
визуальный язык, ясный сценарий первого посещения, независимая оценка дизайна
минимум двумя людьми вне команды, тест с новым пользователем, WCAG 2.2 AA и
Core Web Vitals на мобильных и настольных устройствах. Для трафика ориентиры
75-го процентиля: LCP <= 2,5 с, INP <= 200 мс, CLS <= 0,1; до появления
полевых данных фиксировать лабораторные измерения отдельно, не подменяя ими
реальные. Референсы служат для оценки качества, не для копирования кода/дизайна:
2026 Webby Best User Experience (Pentagram Archive) и аналогичные проекты.
Источники критериев: https://www.w3.org/TR/WCAG22/,
https://web.dev/articles/vitals,
https://winners.webbyawards.com/winners/websites-and-mobile-sites/features-design/best-user-experience.

### Граница октябрьского продукта

1. `xprnet.org` - профессиональный презентационный сайт GCSC с правдивым
   разделением доступного сейчас и будущего, минимум hero-видео и одним
   объясняющим роликом, понятным переходом в `gcsc.store`.
2. `gcsc.store` - адаптивное веб-приложение: владелец регистрируется, описывает
   ремонт текстом или голосом, правит AI-черновик и публикует заявку; подрядчик
   регистрируется, видит обезличенный анонс, оплачивает доступ к конкретному
   лиду, видит разрешённые детали, правит AI-черновик предложения и отправляет
   его; владелец видит предложение. Email/password работает без WebAuth.
3. Запусковое упрощение: фиксированная цена за **конкретный** лид в USD,
   без аукциона, эксклюзивного таймера и автоматических 50% возвратов. Это
   временная продуктовая гипотеза, а не изменение долгосрочной спецификации
   Priority Access. Публикация заявки владельцем предполагается бесплатной;
   окончательные цена, лимит покупателей, условия возврата и юридический текст
   утверждаются до включения реальной оплаты. XPR/WebAuth остаётся отдельным
   тестовым путём, не условием обычной регистрации или покупки в USD.
4. Не показывать как действующие: escrow/custody, кредиты, стейблкоин,
   страхование, автоматические выплаты, инвестиции и AI-оценку недвижимости.
   Мобильный APK и весь набор из 60 возможностей не входят в этот веб-релиз.
